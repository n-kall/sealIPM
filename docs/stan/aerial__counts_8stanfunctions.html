Simulate aerial survey counts.

Generates aerial survey counts using the same negative-binomial observation model as aerial_count_lpmf(). For observation i, the expected count is:

mu * population_total[aerial_year[i]].

If the expected count is zero, the simulated count is set to exactly zero.

Parameters
aerial_yearState-process year index for each simulated observation.
population_totalTotal population size in each state-process year.
muAerial observation rate.
phiNegative-binomial precision parameter.
Returns
One simulated aerial survey count for each element of aerial_year.
