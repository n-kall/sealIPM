Simulate the discrete state process using one joint fate ODE.

The fitted survivor boundary is integerized once. Each forecast year uses integer ageing, binomial births and sex allocation, one joint competing- risks ODE per non-empty demographic group, and multinomial fate sampling.

real  birth_rate,

Age integer survivors and simulate newborns.

Female groups occupy indices 1:n_age_classes; male groups occupy (n_age_classes + 1):(2 * n_age_classes). The final group for each sex is a plus group. Births and newborn sex allocation use binomial draws.

Parameters
previous_survivorsInteger survivors from the preceding year.
birth_rateProbability that an adult female gives birth.
n_age_classesNumber of age classes for each sex.
Returns
Integer population composition for the new year.
