# Forecast IPM

Forecasts future years from a fitted IPM

## Usage

``` r
forecast_ipm(fit, future_data, species, prior_spec = NULL, ...)
```

## Arguments

- fit:

  fit object

- future_data:

  future data

- species:

  which species

- prior_spec:

  prior settings

- ...:

  unused

## Value

forecast results
